### Part 3｜Revit 基礎①：視圖＋導覽

- BIM 不是畫 3D：點一個元件看 Properties——每個元件自帶參數，
  這就是之後要用的「結構化資料」的起點
- 開 `CAD/` 範例檔：專案瀏覽器、平面／立面／剖面／3D 視圖；
  **視圖是「看模型的不同窗口」，不是圖紙**
- 導覽：縮放、平移、3D orbit（ViewCube）
- 樓層：樓層決定高度、元件依附樓層放；示範新增一個樓層
- 暫時隱藏／取消隱藏：模型亂的時候先藏再說

### Part 4｜Revit 基礎②：建＋改＋排程

- **關鍵觀念：類型（Type）vs 實例（Instance）**：
  改類型影響全部同類型元件，改實例只影響這一個；
  之後用 MCP 讀寫資料，操作的正是這些參數——今天先用手改，有感覺再交給 agent
- 跟做「單間小屋」：
  1. 平面圖畫四面牆圍起來
  2. 放一扇門、兩扇窗（門窗一定要選到牆上才放得進）
  3. 加樓板；平屋頂（選做）
  4. 放房間＋房間標記（房間自帶面積，這就是資料）
  5. 切 3D 看、截圖
  6. 建一張門明細表（schedule 就是「查資料」，10/2 換 agent 來做同一件事）
  7. 存檔：`組名_姓名_0918.rvt`，放本機
- 常見卡關先講：門窗放不進去（沒選到牆）、牆沒圍起來房間放不下、樓層不對高度錯
