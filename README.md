## 交件流程（小組 fork＋PR）

各組協作＋交件都走同一套（10/2 課上教一次）：

**業師前置**
- 主 repo `main` 開分支保護：禁直接 push，只能 PR 合併
- `20261030/第X組_應用名稱/` 是發表資料夾模板（格式待定）

**小組流程**
1. 組內一人 fork 主 repo（組 fork），把另 3 人加為 collaborator
2. 組內協作：每人開自己分支、組內互看互 merge
3. 收斂到一條分支，內容只動 `20261030/第X組_應用名稱/`（模板複製改名，如第1組_應用名稱）
4. 從組 fork 發 PR 回主 repo，標題寫組別＋題目；業師 review 後 squash merge（一組一個 commit）
5. 截止 10/29 23:59；merge 完的版本就是 10/30 發表＋投票用
