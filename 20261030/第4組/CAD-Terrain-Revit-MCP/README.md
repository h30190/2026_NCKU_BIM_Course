# CAD Terrain Revit MCP — v3 原型

CAD 地形、房屋高度來源與道路面轉 Revit 2024 的學習專案，由使用者提出需求，AI 協助開發。

**狀態（2026-11-05）：23 項自動測試通過，已完成小型合成 DWG 的選檔、檢查、採用、Revit 建模及 .rvt 另存實測。此驗證不代表所有實際 CAD 都可直接成功。**

## v3 新增功能

- 房屋高度來源：可調假設值、屋高文字、樓層數乘假設層高、指定圖層的屋頂絕對 Z。
- 文字僅配對到唯一包含文字插入點的房屋輪廓；同輪廓內不同數值視為衝突，不會任意選一個。
- 沒有高度或衝突時，可用假設高度並註明，或略過。預設採假設高度。
- 樓層數不是實測屋高；每層高度可調。屋頂 Z 是絕對標高，需扣掉估計地面，不能直接拿來當屋高。
- 道路可多選圖層，使用「封閉路面範圍」或「中心線加假設寬度」。須明確確認資料類型。
- 道路生成灰色 DirectShape 網格面，依預處理地形三角網貼合並抬高5公分；沒有路基厚度、整地或道路工程設計。
- 預處理輸出平面 preview.html、逐棟 building-heights.csv 及 report.json。

## 環境與安裝

Windows x64、Revit 2024、可正常啟動的 AutoCAD Core Console（測試用 2024）。需要含 tkinter / pip 的 Python 3.12 x64。
商用軟體與其授權不包含在本專案。

從原始碼安裝，在專案資料夾執行（請換成自己的 Python 路徑）：

```powershell
.\SETUP_DEPS.ps1 -PythonExe 'C:\Python312\python.exe'
.\BUILD.ps1
.\INSTALL.ps1 -PythonExe 'C:\Python312\python.exe'
```

完整本機安裝包已附 vendor 與編譯 DLL，可以略過前兩步。安裝會備份本套件原有登記；下一次啟動 Revit 載入。
先存檔、關閉再重新開 Revit。建議新開「建築」專案。

## 操作

1. 增益集 → **CAD 基地 MCP v3 → 選擇 CAD**。
2. 「地形與圖面單位」頁選 CAD、實際尺度、地形來源、房屋輪廓。
3. 「房屋高度與道路」頁設定高度模式與來源圖層。無高度時採假設值的數值在第一頁設定。
4. 要建立道路，選道路資料類型與圖層；中心線模式才使用假設路寬。原圖兩側道路邊線不可直接當中心線。
5. 檢查 → 開啟平面預覽 → 確認道路範圍、房屋高度來源數量 → 採用。
6. 回 Revit 按建立地形與房屋，結果會列出房屋及道路成功／略過數量；另存 .rvt。

換 CAD 或設定後須重新檢查採用。v2 已採用的資料不能直接拿給 v3 建模。
換資料不會刪除舊模型；同一資料編號不重複建立。若部分元素略過，不會自動重試。

## 高度格式

屋高文字：`12`、`12m`、`H=12m`、`高度:12`、`12500mm` 等。未寫單位時使用指定的屋高文字單位。
樓層文字：`3F`、`3層`、`3樓` 或在已指定樓層圖層中的純數字。
不得選房號／門牌圖層作樓層數；文字位置在屋外或多棟邊界上不自動猜配。
屋頂 Z 模式必須選代表屋頂標高的圖層；同輪廓內需一致且高於估計地面。全 Z=0 不能辨認屋高。

## 道路限制

封閉模式把線網內的封閉面當成路面，必須檢查是否把街廓、分隔島或建築當路面；不自動判讀道路語意或配對兩側邊線。
未封閉線不猜測補齊，只顯示略過數量。若僅有開放的道路邊線，請在CAD副本補齊正確路面邊界或整理中心線。
道路裁切到地形範圍。Revit可能採不同地形三角化，因此仍需檢查懸空與穿地。
平面預覽是資料檢查圖，不是已生成的Revit模型。

## 其他限制

文字標高 IDW 地形是示意，不是測量成果；房屋基座同樣是估計地面。
ModelSpace 以外、圖塊及外部參考不展開。房屋量體沒有原生牆、窗、樓板與屋頂。
使用局部座標與地形資料凸包，未設共用座標或地籍邊界。
地形最多15,000點、房屋3,000個、道路50,000三角面。需人工檢查量體與資料品質。

## 地形點超過 15,000 時

CAD Z 模式可設定「等高線簡化容許偏移（公尺）」；0 表示不簡化。只簡化固定 Z 的線，保留端點及基地凸包頂點；高程變化線不簡化。非零值允許平面線形近似，須檢查精度。文字插值網格間距不控制這個模式。處理後仍超過上限時，先裁切 CAD 副本範圍，不會強行建模。

此功能新增兩項測試（當時合計19項，現為23項）：固定高程線減點、變高程線不被削平。本次只更新Python流程，關閉選檔視窗再按「選擇 CAD」即可載入；不必重新啟動Revit。

## 國土測繪981編碼預設

選檔視窗預設啟用「國土測繪981編碼」。辨識到唯一對應圖層時，套用公尺、CAD原始Z、9810101計曲線與9810102首曲線一起使用；支援編碼後加底線中文名稱。單位、主／第二圖層、高程模式及簡化值均可調整，也可選自訂。未辨識或編碼重複時不猜測。

9810101是計曲線、9810102是首曲線；實際垂直間距依圖資而異，不會把所有檔案寫死為5m／25m，也不會按線粗重寫Z。圖層編碼依據：https://ws.moi.gov.tw/001/Upload/CustomFile/Nlsc/Law/d7e623ce-aecb-48bc-991f-514deb6e7506.pdf

1m簡化容許偏移只是本工具的可調起始設定，不是官方精度規範。兩圖層合併仍超過15,000點時，先裁切基地或自行決定可接受的簡化偏移，不自動遺漏細等高線。本次共23項測試通過。
