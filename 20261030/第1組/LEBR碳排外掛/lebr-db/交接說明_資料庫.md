## 怎麼確認環境正常

在這個資料夾執行（需要 .NET SDK 10），應顯示「全部通過」：

```
dotnet run --project csharp/LebrDatabase.Tests -f net8.0
```

重新產生 JSON（需要 Python 3）：

```
python -I scripts/build_json.py .
```

只有重抽 PDF 時，才需要 `pymupdf` 與 `openpyxl` 這兩個 Python 套件。

- 每一筆都用兩種方法交叉驗算：一是數字之間的關係（新建 = 基層 + 表層、減碳量 = 本構件 − 基準），二是 PDF 純文字比對，307 筆全部一致。

- `LebrDatabase.cs` 在 .NET Framework 4.8 與 .NET 8 都測試通過。
- 外掛用這份資料庫重現手冊附錄三：CFR 20.51%、1+ 級。

## 注意事項

- **不要直接改 CSV 或 JSON**，一律透過 `corrections.csv`。
- **構件代號是草案**（例如 `IW-M-03`、`F-L-G01`）。已經有模型在用，要改規則請先和外掛組、建模者協調。
- 資料庫更新後，外掛要重新安裝，新的 JSON 才會複製到 Revit 的外掛資料夾。
- 手冊 PDF 請自行從內政部建築研究所網站下載（`extract_lebr_tables.py` 依 2025 年 7 月版的頁碼寫成，PDF 頁碼 = 印刷頁碼 + 12）。
