## 怎麼跑起來

需要 Windows、Revit 2027、.NET SDK 10。**課堂用的 Revit 2024 也能編譯（`install.ps1 -RevitVersion 2024`），組員已在 2024 跑過「開始計算」；「代號 JSON」還沒在 2024 上試過。** 以下在 `lebr-db` 資料夾執行。

1. 跑測試，應顯示「全部通過」：

    ```
    dotnet run --project csharp/LebrDatabase.Tests -f net8.0
    ```

2. 關掉 Revit，編譯並安裝（Revit 開著時，加 `-Folder LebrCarbon_5` 這類新資料夾名稱）：

    ```
    powershell -ExecutionPolicy Bypass -File revit-addin/install.ps1
    ```

3. 開 Revit 2027，安全性提示選「永遠載入」。之後的操作見 `組員操作指南.md` 第一節。

**不用編譯的安裝方式**：關掉 Revit，雙擊交接包最上層的 **安裝外掛.bat**。它會自動找出電腦上的 Revit 2024～2027，裝好對應的版本。

## 已驗證的事

- **計算引擎**：手冊附錄三算出 CFR 20.51%、1+ 級，各項和手冊相差 0.05% 以內。74 項測試在 .NET Framework 4.8 與 .NET 8 都通過。

- **Revit（從模型擷取）**：測試模型填了下表的代號後，算出 **1+ 級、CFR 24.60%**、EEC 442,059 kgCO2e，0 個未對應。

### 測試模型

`測試模型/LEBR_test.rvt` 是課程模型 `NCKU_9hours_intro_course.rvt` 的複本，已建立參數。最後一次存檔應該包含下表的值，但無法直接從檔案確認；打開後沒有的話，照表重填即可。

| 帷幕嵌板 System Panel: Glazed | `LEBR_Code` | `CWW-G14-ALPVC` |
| 樓板 Generic Floor - 400mm | `LEBR_Code` | `F-G01` |

## 已知問題與注意事項

1. **資料庫是草稿**，結果視窗會一直顯示提醒，等資料庫負責人核對完成。
2. **屋頂判斷規則的最新修正還沒在 Revit 驗證**。規則是：沒有房間時，模型最高樓層上的樓板視為屋頂板。
3. 原開發電腦的 `Addins\2027\` 底下有 `LebrCarbon`、`_2`、`_3`、`_4` 四個版本（目前 `LebrCarbon.addin` 指向 `_4`），Revit 關閉後可清掉舊的。
4. **Snowdon Towers 範例檔（180 MB）在原開發電腦會讓 Revit 卡死**，與外掛無關，測試請用小模型。
5. 外掛沒有數位簽章，換安裝資料夾就會再跳一次安全性提示。
6. 窗的面積讀實例或類型的「寬度、高度」參數；族群參數名稱不同時會列入未對應，需要擴充 `RevitQuantityProvider.Length()`。
7. **估算結果只在「計算並儲存」時寫入**：取消勾選「使用估算」會清除 `LEBR_CFs` 與 `LEBR_EstimateJson`。
8. **設計案缺少 Sp 或 F 時**：引擎只讓設計案主結構未計算，基準案仍會計算；但結果視窗目前只顯示「主結構未計算」，尚未顯示基準案數值。
9. **「專案設定」只在 Revit 2027 實測過**；2024～2026 尚未測試。
10. **「代號 JSON → 套用代號」會覆寫專案參數**（包含 `I`、`SaD`、`Fu`、`L`、`D0`、`Rs` 等示範值），用於正式模型前請先另存副本。

## 結構碳排估算（新增功能）

- 入口：「專案設定」勾選「使用估算」後，按「開啟估算」。
- 數量來源：結構柱、結構梁、所有樓板、混凝土類結構牆（結構 = 是）、結構鋼筋（柱、梁，加上樓板的區域配筋與路徑配筋）。
- 材料係數：附錄一 P-LCC（`data/estimate/附錄一_P-LCC_2022.csv`，只取「總碳排量」欄）。
- 計算：CFsn = An × L + Bn × M；地上（標高 ≥ 0）與地下（標高 < 0）各自加總後合計為 CFs。
- 鋼筋質量 = 鋼筋體積 × 7850 kg/m³（已用模型驗證）。
- 寫入：「計算並儲存」會寫入 `LEBR_CFs` 與 `LEBR_EstimateJson`。CFs 作為設計案主結構值，不再計算 Sp、F；取消勾選「使用估算」會清除這兩個參數。
- 已知限制：
  - 混凝土牆以材質名稱判定（含 Concrete 或「混凝土」）。
  - 結構梁的體積在部分模型讀不到計算參數時，改加總幾何實體體積。
  - 樓板鋼筋的讀取尚未在含樓板鋼筋的正式模型上驗證。
- 測試：`csharp/LebrDatabase.Tests` 包含估算的手算、標高邊界、迴圈與錯誤輸入測試。
