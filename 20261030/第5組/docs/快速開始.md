# 快速開始

## 環境

- Windows、Revit 2024，課程模型依課程要求取得。
- .NET SDK（可建置 net48 專案）與 .NET Framework 4.8 targeting pack。
- Go 1.26 或以上；首次建置需下載 Go／NuGet 相依套件。
- PowerShell 5.1 或 7。腳本使用 UTF-8 BOM，供 Windows PowerShell 正確讀取中文。
- RevitAPI.dll、RevitAPIUI.dll 須位於 `C:\Program Files\Autodesk\Revit 2024`，或自行調整專案參考路徑。

## 建置及安裝

先將整個小組倉庫 clone 到本機，再在 `20261030/第5組/GreenPassport` 開啟終端機：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test
powershell -NoProfile -ExecutionPolicy Bypass -File .\revit-plugin\install.ps1 -Version 2024
powershell -NoProfile -ExecutionPolicy Bypass -File .\start-backend.ps1
```

安裝腳本將 DLL 置於使用者的 Revit Addins 版本目錄，不需改動 Revit 安裝資料夾；安裝後儲存模型並重新開啟 Revit。啟動腳本在背景執行後端，資料及紀錄位於 `backend/data` 與 `backend/logs`。首次啟動會自動建立空白 SQLite 資料庫。

請使用同一版本的後端與外掛；新版工作流程必須帶入預留擁有者、完整目標識別及資料版本。HTTP 409 代表資料已變動或預留屬於其他需求，請重新載入，不要略過錯誤直接修改模型。

本機圖台：[http://127.0.0.1:8080/dashboard](http://127.0.0.1:8080/dashboard)。若 8080 已被其他測試服務使用，請先確認並停止原服務；不要同時啟動兩份資料庫的後端。

## 完整示範

先從 [A、B 模型共享資料夾](https://drive.google.com/drive/folders/1hs0NVZTUX0AQ8MwTbN5Lx1MZO2URrYo0) 下載兩個 RVT。B 模型共享檔目前名為 `B模型_新建案.0001.rvt`，開啟後另存為 `B模型_新建案.rvt` 作為測試副本；詳見[模型與資料說明](模型與資料說明.md)。

1. 開啟來源 A 模型。在「A｜擷取與建立護照」選取需建檔的門，建立護照。
2. 到「護照清單與審核管理」，確認八項核心資料及檢核人／說明後核准；Approved、Available 且有數量才會進入候選。
3. 同時開啟 B 模型，選取一扇門，點「B｜確認需求、配對與替換」。
4. 確認門寬、高、厚度、開啟方式、方向、用途、材質、淨寬，再按「執行三態配對」。
5. 選擇 Matched 項目，按「預覽並預留」，確認狀態為 Reserved，再按「執行 B-1 替換」。
6. A 模型須在同一個 Revit 中保持開啟。程式依來源模型名稱及 UniqueId 定位原門，載入獨立命名的來源族群後替換。
7. 在 B 模型 3D 視圖以「著色」或「擬真」檢查外觀；性質中的族群名稱為 `GP_Source_…`、類型為 `GP_GP-D-…`，備註含 `GreenPassport:…`。
8. 在圖台確認狀態為 Allocated、目標模型與 Element ID，再儲存 RVT。

Allocated 表示模型配置；Installed 才是獨立的現場安裝狀態。外掛完成模型替換不代表實體已安裝。

## 更新舊版已配置門

選取已配置的門，按「更新已配置門／族群與材質」。必須有護照備註，且後端記錄為 Allocated、目標模型與 Element ID 相符。更新不會重新預留護照，會補登此次前後 TypeId。

若 Revit 已更新但後端稽核失敗，請保留畫面錯誤資訊並補登，不要反覆執行替換。

## 解除安裝與回復

先儲存模型並關閉 Revit，再執行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\revit-plugin\uninstall.ps1 -Version 2024
```

解除安裝會將 manifest、新版 `TemporalBimReleases` 及舊版部署目錄移到同層 `TemporalBimRemoved-…` 備份，不直接刪除。需要回復時，關閉 Revit 後把備份中的項目移回上一層再重啟。可先加 `-WhatIf` 預覽範圍；其他外掛不在移動清單。
