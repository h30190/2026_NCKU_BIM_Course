- 快照：`418237` 第一階 (-1.26, 4.28)，來源 `user_selected_direct:lowest_run_path_start`；`417650` 移到 `unresolved_stairs`。

- 檢討網頁自動產生。以同一份快照和設定跑引擎：20 間居室都是「符合」，距離 8.36～24.04 m，上限 50 m。

## 程式驗證

- 外掛核心測試、`node check.js`、`engine/rules.test.js` 通過。
- 安裝包解壓到另一個資料夾、裝到暫存的使用者目錄，再從 DLL 取出網頁，在斷網瀏覽器載入真實快照，無錯誤。

## 尚未驗收

- 其他樓層、其他模型、其他電腦。
- 穿過本層的樓梯偵測、房間內獨立柱與孔洞，只有 API 文件核對、核心測試或引擎模擬，沒有真實模型實測。
- 連結模型、舊式樓梯、多層樓梯仍未支援。Revit 2027 未用這一版建置。
- 判定用的類組、防火構造由使用者確認，規則包尚未核定；路線穿過同戶居室時只寫在附註，樓梯外框尚未當障礙物。
