# 執行步驟說明 — Revit AI 通風開窗

這份說明帶你從零開始，用資料包附的範例模型跑完整個流程：

```
分析氣象 → 產生開窗方案 → 比較方案（評分、室內風流）→ 在 Revit 建窗 → 人工檢查 → 匯出成果
```

跑過一次範例之後，第 6 節說明怎麼換成自己的案例。

版本：2026-10-30（成大建研所 115-1 BIM 課程 第 2 組）

---

## 1. 資料包內容

| 資料夾 / 檔案 | 用途 |
|---|---|
| `server.mjs` | 主程式，啟動後提供網頁介面 |
| `web/` | 網頁介面 |
| `lib/`、`engine_member3/`、`cli/` | 程式（不用改） |
| `data/` | 模型資料、窗型、規則、氣象檔（`data/weather/*.epw`） |
| `revit_models/` | 還沒開窗的原始模型 `model_01.rvt`、`model_02.rvt` |
| `examples/` | 完成的範例成果（含建好窗的 rvt），可以對照自己的結果 |
| `output/` | 執行結果會存在這裡（一開始是空的） |
| `docs/workflow_model_A.md` | 套用到新模型的完整流程 |

兩個範例模型：

| 編號 | 名稱 | 特色 |
|---|---|---|
| 01 | 商辦標準層 01 | 服務核在中央 |
| 02 | 商辦標準層 02 | 服務核貼北牆與西牆 |

## 2. 事前準備（只需要做一次）

### 2-1. 安裝 Node.js 22 以上

- 到 https://nodejs.org 下載 LTS 版安裝，或在 PowerShell 執行：

  ```powershell
  winget install OpenJS.NodeJS.LTS
  ```

- 安裝完**重新開一個** PowerShell，確認版本是 v22 以上：

  ```powershell
  node --version
  ```

這個程式不需要 `npm install`。

### 2-2. Revit 2026

資料包裡的 `.rvt` 都是 **Revit 2026** 格式，Revit 2024 / 2025 打不開。

### 2-3. Revit MCP 外掛

建窗、檢查模型都要透過 Revit MCP 外掛（課程使用 `shuotao/REVIT_MCP_study`），請依該 repo 的說明安裝到 Revit 2026。

裝好後 Revit 上方會有 MCP 的功能區按鈕，啟動後會在本機 port **8964** 等待連線。

> 不連 Revit 也可以先玩第 4 節的「步驟 3」：氣象分析、產生方案、評分、室內風流、手動調整都不需要 Revit。

---

## 3. 啟動程式

1. 在檔案總管打開資料包資料夾（有 `server.mjs` 的那一層）。
2. 在空白處按右鍵 →「在終端中開啟」，打開 PowerShell。
3. 輸入：

   ```powershell
   node server.mjs
   ```

   看到 `Window Agent API: http://localhost:3080` 就是啟動成功。
4. 用瀏覽器打開 **http://localhost:3080**。

注意：

- PowerShell 視窗**不要關**，關掉程式就停了。要停止時在視窗裡按 `Ctrl + C`。
- 程式只接受本機連線，同網路的其他電腦連不到，不用擔心別人操作你的 Revit。
- 如果 3080 被佔用，可以換一個 port：

  ```powershell
  $env:PORT = 3081; node server.mjs
  ```

## 4. 用範例模型跑一次完整流程

### 4-0. 在 Revit 開啟模型（先備份）

1. 在 Revit 2026 開啟 `revit_models/model_01.rvt`。
2. **先「另存新檔」成一份工作檔**（例如存到桌面 `model_01_試做.rvt`），之後都在工作檔上操作，原始檔保持沒開窗的狀態。另存後專案名稱會變，程式會改用牆的 ID 自動辨識，不影響使用。
3. 從 Revit 功能區啟動 MCP 外掛。

> 一次只能有一個程式連 MCP。如果同時開著 Claude Code 等其他 MCP 連線，請先在功能區釋放，否則會連不上（409）。

### 4-1. 步驟 1：模型

1. 「模型」選 `01 — 商辦標準層 01`。
2. 按「檢查 Revit 連線與模型」。
3. 應該顯示 `✓ … 8 道牆、12 根柱、1 個房間都和資料一致`。

### 4-2. 步驟 2：載入窗型

1. 按「檢查模型內的窗型」。
2. 應該顯示 `✓ 14 個窗型都已載入`。
3. 如果有缺，在 Revit「插入 > 載入族群」載入畫面上列出的族群（說明見 `docs/workflow_model_A.md` 的 B 節）。

### 4-3. 步驟 3：依氣象選擇方案

**(1) 設定條件**

| 欄位 | 說明 | 範例 |
|---|---|---|
| 氣象檔 | `data/weather/` 裡的 EPW | 台南 TMYx |
| 月份 | 空白 = 全年；只看夏季就填 `6,7,8` | 空白 |
| 可開窗氣溫 | 這個溫度範圍內才算可以開窗 | 18–30 °C |
| 時段 | 這個時段內才算可以開窗 | 8–22 時 |

**(2) 按「分析氣象」**，看三樣東西：

- **風花圖**：各方位的風出現頻率，顏色越深代表風越強。可以切換「只看可開窗時數」或「全部時數」。
- **各方位迎風分數**：曲線是牆面朝向各方位時的分數，橘點是這棟樓的四面外牆，越靠外圈代表那面牆越吃得到風。
- **逐月風速表**：每個月的可開窗時數、平均與最大風速、主風向、平均氣溫。

展開「方案步驟 1：迎風分數計算過程」可以看到公式、每面牆的計算數字，以及哪些風向貢獻最多。

**(3) 按「產生方案」**，下方會出現 3 張方案卡。每張卡包含：

| 項目 | 怎麼看 |
|---|---|
| 右上角大字分數 | 滿分 100。綠色 ≥ 95、藍色 ≥ 85、橘色更低。紅色 ✗ 代表未達法規 5% 通風面積 |
| 名次標籤 | 第 1 名～第 3 名；自己調整的方案標「手動」 |
| 分數組成條 | 迎風方向（滿分 50）＋ 對流通風（滿分 40）＋ 避開服務核（滿分 10） |
| 三格數字 | 通風面積 vs 法規需求、EEWH VP（目標 ≥ 0.10）、估算風量 |
| 平面示意圖 | 窗的位置（藍色）、柱、服務核、主風向（綠色箭頭） |
| 為什麼是這個窗型 / 窗數 | 展開後有「加窗過程」和「窗型比較」兩張表 |

注意：分數只比較「通風好不好」，**不代表合不合法規**；法規看紅色 ✗ 與通風面積那一格。

**(4) 按「室內風流」看大圖**

- 藍色深淺是室內風速，留白是死角；黑色流線是風從哪扇窗進、往哪裡走。
- 綠色窗是進風，橘色是出風，灰色是幾乎沒有氣流。
- 右邊的**通風覆蓋率**是室內風速 ≥ 0.2 m/s 的面積比例，越高越好。
- 上方下拉選單可以切換方案比較。
- 風向用的是氣象分析的主風向。這是 2D 試算，只用來比較方案，不是實際風速。

**(5) 需要時手動調整**

1. 在想要修改的方案卡按「手動調整窗數/窗型」。
2. 下方會列出每面外牆，可以改窗型和窗數（0 = 不開窗），旁邊會顯示最多能放幾扇。
3. 按「試算並另存新方案」，會多一張 `P1-M1` 這類的卡片，原方案不變。
4. 不要的手動方案按卡片上的紅色「刪除」。自動產生的方案不能刪。

**(6) 點選要用的方案卡**，卡片外框會變藍色。

### 4-4. 步驟 4：在模型中建立窗扇

1. 在「確認方案編號」輸入剛才選的方案編號（例如 `P1`），按「確認方案」。
2. 畫面會列出模型裡既有的窗：
   - 本工具之前建的窗：會自動刪除
   - 不是本工具建的窗：預設保留；和新方案位置重疊的必須勾選刪除
3. 按「刪除舊窗並建窗」，等它一扇一扇建完。
4. 結果表格每扇都應該是 `pass`，窗扇是 `interior`。
5. 建錯了可以按「還原這次建窗」，會刪除這次建的窗。

### 4-5. 人工檢查（在 Revit）

1. 在 3D 視圖確認每扇窗都有正確切開牆，窗扇朝室內。
2. 「協同作業 > 干涉檢查」，選窗對結構柱和牆。
3. 回到網頁步驟 4，選擇「牆體切割」和「干涉檢查」的結果，填入檢查人，按「寫入 VC-006」。

### 4-6. 步驟 5：匯出最終檔案

1. 按「匯出最終檔案」，會產生 `output/final_model01_P1_時間/`，裡面有：

   | 檔案 | 內容 |
   |---|---|
   | `1_selected_proposal.json` | 選定的方案、氣象、假設 |
   | `2_mcp_commands.json` | 實際執行的 MCP 指令 |
   | `3_build_report.json` | 逐窗結果、窗的 ElementId |
   | `4_ventilation_checklist.json` | 規範檢核表 VC-001～VC-008 |
   | `README.md` | 成果摘要 |

2. **在 Revit 另存 rvt**（MCP 沒辦法存檔），例如 `model_01_P1_windows.rvt`，放進上面的資料夾。
3. 可以和 `examples/model01_P1/` 對照，結果應該一致。

---

## 5. 換方案、換條件

- **換方案**：回到步驟 3 點另一張卡，再做一次步驟 4。前一組方案的窗會自動刪除。
- **換季節**：月份填 `6,7,8`（夏）或 `12,1,2`（冬），按「產生方案」。台南 4–9 月主風向是南風，10–3 月是北風，排名和室內風流都會跟著變。
- **換地點**：把該地的 EPW 放進 `data/weather/`，重新整理網頁後就能在「氣象檔」選到。下載方式見 `data/weather/how_to_download_epw.md`。

## 6. 套用到自己的案例

自己的模型需要準備三樣東西，完整做法見 **`docs/workflow_model_A.md`**：

1. **模型**：外牆是一般牆並圍成封閉環、標準層在同一樓層、服務核用內牆圍起來、專案北向正確，先不要放窗。
2. **窗型**：從 Revit **英文公制**族群庫載入 `M_Window-Casement-Double` 或 `M_Window-Double-Hung`（中文族群庫的名稱引擎認不得）。
3. **模型資料**：在 `data/model_03/` 放 `building_data.json`（牆、柱、房間）和 `window_families.json`（窗型），格式照 `data/model_01/`；再到 `data/models.json` 登錄一筆 `model_id: "03"`。

登錄後**重新啟動程式**（`Ctrl + C`，再 `node server.mjs`），步驟 1 的模型選單就會出現你的案例，之後照第 4 節操作。

新模型一開始沒有預設方案，步驟 3 會顯示找不到檔案，這是正常的，按「產生方案」就好。

## 7. 常見問題

| 狀況 | 原因／處理 |
|---|---|
| 打 `node` 顯示找不到指令 | Node.js 沒裝好，或安裝後沒有重開 PowerShell |
| 網頁打不開 | PowerShell 裡的程式沒在執行，或被關掉了；重新 `node server.mjs` |
| 步驟 1 連不上 Revit | Revit 沒開、MCP 外掛沒啟動，或被其他程式佔用（409）；先在功能區釋放其他連線 |
| port 8964 被佔用 | 用 `REVIT_MCP_study` repo 裡的 `scripts\release-port.ps1` 釋放 |
| 步驟 1 顯示作用中專案不是這個模型 | Revit 目前在前景的是別的專案，切換到要建窗的那個模型視窗 |
| Revit 打不開 rvt | 版本不對，資料包的模型是 Revit 2026 格式 |
| 步驟 2 顯示缺窗型 | 在 Revit「插入 > 載入族群」載入；名稱必須和畫面上一字不差 |
| 「為什麼是這個窗型 / 窗數」說沒有紀錄 | 方案檔是舊版產生的，按「產生方案」重新計算 |
| 室內風流顯示「只支援矩形平面」 | 外牆不是正南北、東西向；其他功能照常可用 |
| 手動方案顯示紅色 ✗ | 通風面積未達法規 5%，加窗或換大一點的窗型 |
| 建窗時 Revit 跳出錯誤對話框 | 窗切不開牆或重疊，報告會記錄是哪一扇；按「還原這次建窗」後換方案或手動調整 |
| 想從頭再來 | Revit 關閉工作檔不存檔，重新從 `revit_models/` 另存一份；`output/` 裡的檔案可以直接刪除 |

## 8. 試算的限制（發表或引用時請說明）

- 法定有效通風面積、辦公區面積、窗牆比上限 40%、評分權重都是 PoC 暫定值，正式使用前須由建築師或門窗廠覆核。
- 評分只比較自然通風，不含採光、日射得熱。
- 估算風量與室內風流都是相對值，只用來比較方案，不是法規計算或 CFD。
- 室內風流是 2D 平面位勢流：不考慮窗高、樑、家具隔間、渦流與熱浮力，風壓係數用低層建築經驗值，室外風速沒有依樓高修正，而且只用主風向一個方向。
