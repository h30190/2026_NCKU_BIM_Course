# 下載 EPW 氣象檔教學

EPW 是逐時氣象資料檔(風向、風速、氣溫等)。Agent 會依你選的 EPW 計算各面外牆的風向分數,所以**換建築所在地時要換 EPW**。

## 1. 下載

1. 開啟台灣氣象檔頁面:
   https://climate.onebuilding.org/WMO_Region_2_Asia/TWN_Taiwan/index.html
2. 在頁面中找離建築**最近的測站**,點檔名下載 `.zip`。
3. 解壓縮,取出裡面的 `.epw` 檔(其餘 `.ddy`、`.stat` 等檔案用不到)。

## 2. 怎麼看檔名

`TWN_SOR_Tainan.593580_TMYx.2011-2025.zip`

| 片段 | 意思 |
|---|---|
| `TWN` | 台灣 |
| `SOR` | 區域:`NOR` 北、`CNR` 中、`SOR` 南、`ESR` 東、`OIR` 離島 |
| `Tainan.593580` | 測站名稱與站號 |
| `TMYx` | 典型氣象年(由多年實測資料挑選拼接而成,不是某一年的實際天氣) |
| `2011-2025` | 取樣的資料年限 |

選擇建議:
- 同一站有多個年限時,**優先選年限最新的**(如 `2011-2025`)。同一個專案的比較請固定用同一個年限。
- 同一城市有多個測站時(例如台南有 `593580`、`595500`、`Tainan.AP.467430`),選離基地最近、地形與基地相近的那一個。
- 機場站(`AP`)通常空曠、風速偏高;市區基地的實際風速可能較低。

## 3. 放到哪裡、怎麼用

把 `.epw` 放在任何位置都可以,執行時用 `--epw` 指定路徑(路徑有空格要加引號):

```bash
node agent/generate.mjs --epw "D:/氣象/TWN_SOR_Tainan.593580_TMYx.2011-2025.epw"
```

**建議一律用 `--epw` 指定。** 沒指定時,系統只在專案內剛好只有一個 `.epw` 才會自動使用;找到多個會報錯並列出,不會自己猜。

常用選項:

```bash
node agent/generate.mjs --epw 檔案.epw --months 6,7,8      # 只看夏季
node agent/generate.mjs --epw 檔案.epw --tmin 20 --tmax 28 # 自訂開窗氣溫
node agent/generate.mjs --epw 檔案.epw --hours 9,17         # 自訂時段(預設 8–22 時)
```

## 4. 確認用對了

執行後第一行會印出氣象地點,例如:

```
Tainan (annual;僅統計 18–30°C、8–22 時,佔 44%),常見風向 N;...
```

請確認:
- 地點名稱是你要的城市。
- 「佔 xx%」不是接近 0。太低代表該地多數時間不適合開窗,結果參考性低;`window_proposals_modelXX.json` 的 `weather.monthly_usable_hours` 可看每月可用時數。

## 5. 常見問題

| 狀況 | 處理 |
|---|---|
| `專案內有 N 個 EPW,請以 --epw 指定` | 加上 `--epw 檔案路徑`。 |
| `找不到 EPW 檔` | 檢查路徑;路徑有空格或中文時加引號。 |
| `不是有效的 EPW:第一行應為 LOCATION` | 檔案不是 `.epw`(可能誤用了 `.zip` 或 `.stat`),請先解壓縮。 |
| `篩選後沒有可開窗的時數` | 氣溫或時段條件太嚴,放寬 `--tmin`、`--tmax`、`--hours`,或加 `--all-hours true` 不篩選。 |

## 6. 注意

- EPW 的「時」是該小時的**結束時刻**(1–24),`--hours 8,22` 代表第 8 到第 22 小時。
- 典型氣象年適合比較方案,不能用來預測某一天的實際風況。
- 資料來源與使用條件以 Climate.OneBuilding.org 頁面說明為準;正式報告請註明出處。
